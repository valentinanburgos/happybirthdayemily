ANIMAL IMAGE GUIDE

The friend-1.svg through friend-7.svg files are cute starter illustrations, so the game works immediately.

To use real animal photos:
1. Add each photo to this folder, e.g. friend-1.jpg.
2. Open friends.js.
3. Change the matching animal.image value, e.g. "assets/animals/friend-1.jpg".
4. For the final collage, save your finished image as emily-chimera.png in this folder.
5. The final screen will show a friendly placeholder until emily-chimera.png is present.

Use image file names with no spaces when possible. PNG or JPG works well for animal photos.
